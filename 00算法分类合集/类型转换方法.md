# 涉及的类型转换 / 字符相关语法整理
这道题是 LeetCode 389.找不同，用到三个核心内置函数：`ord()`、`chr()`

## 1. ord(单个字符)

`ord` 是 **ordinal** 的缩写，英文全称：**ordinal number**，翻译：**序数、序值**。
```python
ord(ch)
```
- 作用：**字符 → ASCII 数字（整数int）**
- 入参：**只能是单个字符的字符串**，不能传多个字母
- 返回：int
```python
ord('a')   # 97
ord('b')   # 98
ord('z')   # 122
```
👉 你的代码里：`ord(ch) - ord('a')`
含义：把 `a~z` 映射成 `0~25`，刚好对应数组 `count[0]~count[25]`
例：`ch='c'` → ord('c')=99，99-97=2 → count[2]

## 2. chr(整数)
```python
chr(num)
```
- 作用：**ASCII数字（int） → 字符**，和 ord 互为逆运算
- 入参：int（合法ASCII码值）
- 返回：单字符 str
```python
chr(97)  # 'a'
chr(98)  # 'b'
```
👉 你的代码里：`chr(index + ord('a'))`
index 是0~25，index+97 转回对应字母。
例：index=2 → 2+97=99 → chr(99) → 'c'
